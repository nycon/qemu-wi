# Configuration Reference

## File Locations

| File | Purpose |
|---|---|
| `/etc/qemu-interface/secrets` | Generated secrets (JWT, DB password, agent token, admin password) |
| `/opt/qemu-interface/backend/.env` | Backend environment variables (installer-managed) |
| `/opt/qemu-interface/host-agent/.env` | Host Agent environment (token, paths) |
| `/opt/qemu-interface/docker-compose.override.yml` | Docker Compose overrides (generated) |
| `/etc/qemu-interface/nginx-platform.conf` | SSL/platform Nginx vhost (not in git) |
| `/opt/qemu-interface/deploy/nginx/nginx.conf` | Base Nginx config (pull-safe) |
| `/opt/qemu-interface/config/ssl.json` | Panel SSL domain status (local, not in git) |
| `/etc/qemu-interface/egress-rules.json` | VM egress filtering rules |
| `/etc/qemu-interface/agent-cert.pem` | Host agent TLS certificate |
| `/etc/qemu-interface/agent-key.pem` | Host agent TLS private key |

## Secrets File

Location: `/etc/qemu-interface/secrets` (permissions: 600)

```bash
JWT_SECRET=<random-64-char>
AGENT_TOKEN=<random-64-char>
DB_PASSWORD=<random-24-char>
ADMIN_PASSWORD=<random-16-char>
SERVER_IP=<detected-ip>
```

These are generated on first install and reused on subsequent runs.

## Backend Environment (.env)

Location: `/opt/qemu-interface/backend/.env`

```bash
# Database
DATABASE_URL=postgresql+asyncpg://qemu:${DB_PASSWORD}@db:5432/qemu_interface

# Redis
REDIS_URL=redis://redis:6379/0

# Security
SECRET_KEY=${JWT_SECRET}
JWT_SECRET_KEY=${JWT_SECRET}

# Host Agent
HOST_AGENT_URL=https://host.docker.internal:8443
HOST_AGENT_TOKEN=${AGENT_TOKEN}

# Storage
DEFAULT_STORAGE_POOL_PATH=/var/lib/qemu-interface/storage

# Panel domain / CORS (locked to SSL domain by installer when cert exists)
PANEL_DOMAIN=panel.example.com
CORS_ORIGINS=["https://panel.example.com"]
ALLOWED_HOSTS=["panel.example.com","localhost","127.0.0.1"]
ALLOW_PUBLIC_REGISTRATION=false
EXPOSE_API_DOCS=false

# SMTP (optional — also editable in Settings UI)
SMTP_ENABLED=false
SMTP_HOST=
SMTP_PORT=587
SMTP_USER=
SMTP_PASSWORD=
SMTP_FROM_EMAIL=
SMTP_FROM_NAME=QEMU Interface
SMTP_USE_TLS=true
```

`SMTP_FROM_EMAIL` is the platform **sender**. Per-tenant alert inboxes are stored in the DB (`notification_email`), not in this file.

## Docker Compose Override

Location: `/opt/qemu-interface/docker-compose.override.yml`

Generated by installer. Contains:
- Environment variables from secrets
- Volume mounts for storage and backups
- Network configuration

## Host Agent Configuration

File: `/opt/qemu-interface/host-agent/agent/config.py`

| Setting | Default | Description |
|---|---|---|
| `AGENT_TOKEN` | from env/secrets | Bearer token for authentication |
| `JWT_SECRET_KEY` | from env | JWT secret for console tokens |
| `STORAGE_BASE_PATH` | `/var/lib/qemu-interface/storage` | VM disk storage |
| `CLOUD_INIT_PATH` | `/var/lib/qemu-interface/cloud-init` | Cloud-init seeds |
| `BACKUP_PATH` | `/var/lib/qemu-interface/backups` | Local VM backup storage (internal backend) |

## VM backup storage backends

Configured in the panel (**Admin → Backups → VM backup storage**), stored as a platform setting (not only env vars):

| Backend | Description |
|---|---|
| `internal` | Keep backups on the host under `BACKUP_PATH` |
| `ftp` | Upload to FTP/FTPS after create (host, port, user, password, path, TLS) |
| `s3` | Upload to S3-compatible storage (endpoint, region, bucket, keys, prefix) |

Optional `keep_local_copy` retains the host file when using FTP/S3. See [Backups](Backups.md).

## Egress Filtering Configuration

File: `/etc/qemu-interface/egress-rules.json`

```json
{
  "enabled": true,
  "rate_limit": {
    "connections_per_sec": 20,
    "burst": 40
  },
  "allowed_ports": [
    {"port": 53, "protocol": "udp", "description": "DNS"},
    {"port": 53, "protocol": "tcp", "description": "DNS"},
    {"port": 80, "protocol": "tcp", "description": "HTTP"},
    {"port": 443, "protocol": "tcp", "description": "HTTPS"},
    {"port": 22, "protocol": "tcp", "description": "SSH"}
  ]
}
```

Managed via the admin panel at **Firewall / Egress** or via API.

## Nginx Configuration

Generated dynamically based on SSL status:

- **HTTP only**: Standard reverse proxy on port 80
- **HTTPS**: Full TLS config with HTTP→HTTPS redirect, HSTS, security headers

Key routing rules:
- `/api/*` → Backend (port 8000)
- `/websockify` → Host Agent VNC WebSocket
- `/*` → Frontend (port 3000)

## Port Reference

| Port | Service | Access |
|---|---|---|
| 80 | Nginx HTTP | Public |
| 443 | Nginx HTTPS | Public |
| 3000 | Frontend (Nginx) | Internal (Docker) |
| 8000 | Backend (uvicorn) | Internal (Docker) |
| 8443 | Host Agent | Internal only (localhost + Docker – never expose publicly) |
| 5432 | PostgreSQL | Internal (Docker) |
| 6379 | Redis | Internal (Docker) |
| VNC | Console WebSocket | Via Nginx `/websockify` only (do not open 6080–6180 publicly) |
